# QuantohlplexOS

> **Built different.**

QuantohlplexOS is a custom Debian-based Linux operating system that combines the best of three worlds:
- **Windows 11** — Modern taskbar with centered icons and frosted glass
- **Windows 10** — Clean, no bloat, no unnecessary features  
- **macOS** — Top menu bar, spotlight launcher, smooth animations

---

## Features
- 🐧 Debian 13 "Trixie" base
- 🖥️ KDE Plasma desktop (stripped, custom only)
- 🪟 Windows app support via Wine
- 🎨 Custom UI — taskbar + top bar hybrid
- ⚡ Custom apps built in C++ Qt:
  - QHlplex Terminal
  - QHlplex Browser
  - QHlplex Settings
  - QHlplex File Manager
  - QHlplex Update Manager
- 🔧 Custom Neofetch with Quantohlplex logo
